# 冲压工艺与模具设计 · 期末刷题

在线使用：**https://74185212.github.io/stamping-exam-review/**

单文件静态页面（`index.html`，数据内嵌，无任何外部依赖），可离线双击打开，手机浏览器同样可用。

## 内容

| 模块 | 数量 | 说明 |
| --- | --- | --- |
| 必考选择 | 25 题 | 一次一题，选完立即判分，附「考点 / 依据 / 排除」三段解析；答题卡可跳题，支持分组、顺序 / 随机、只看未做 / 错题 |
| 思考题 | 39 题 | 按章筛选、关键词搜索、详细版 + 背诵版双答案、自测模式（遮答案）、答案可自行编辑 |
| 章节知识点 | 7 节 | 考前指南 + 第 1—5 章 |
| 拉深大题 | 4 道 | 先做题，点「显示参考答案」才展开解答；另附五步模板与六个易错点 |

## 说明

- 作答记录、答案修改、「已掌握」标记都保存在浏览器 localStorage，换设备或清理缓存会丢失，可在页面内「导出 / 导入」备份。
- 公式使用 CSS 绘制的真根号（上划线覆盖被开方内容），单位正体、变量斜体。

## 快捷键

`A` / `B` / `C` / `D` 作答，`←` `→` 翻题，`Enter` 下一题。
